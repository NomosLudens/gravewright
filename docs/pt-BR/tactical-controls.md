# Controles do cliente tático

O cliente tático Godot mantém o servidor como autoridade. A linha de estado informa se a ação foi aceita ou por que foi recusada; erros do servidor permanecem visíveis enquanto o tabuleiro atualiza.

Use **Mover**, **Atacar** ou **Emboscada** para escolher o modo de ação. O modo ativo permanece destacado. Selecione uma unidade e depois uma célula alcançável ou um alvo válido. O painel possui um botão visível para recolher e reabrir os controles. Em telas menores, o Mestre pode rolar o painel para acessar preparação e ferramentas de terreno; os controles quebram em linhas com alvos de toque maiores e texto legível.

Um ataque continua exigindo ficha KALLISTIS aprovada e arma canônica confirmada. A interface explica esse requisito sem contornar a validação do servidor.
