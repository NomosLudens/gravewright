# Tactical client controls

The Godot tactical client keeps the server authoritative. A visible status line reports whether an action was accepted or why it was refused; server errors remain visible while the board refreshes.

Use **Move**, **Attack**, or **Ambush** to select an action mode. The active mode stays highlighted. Select a unit, then choose a reachable cell or valid target. The control panel has a visible collapse/expand button, and the Master can scroll it to reach setup and terrain tools on smaller screens. Compact viewports use touch-sized controls and larger readable text; rows wrap inside the scrollable panel.

An attack still requires an approved KALLISTIS character sheet and confirmed canonical weapon. The interface explains this requirement; it does not bypass server validation.
